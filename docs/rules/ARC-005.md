# ARC-005 `value-to-zero-address`

**Severidad / Severity:** Alta / High

**Estado / Status:** documentada; el detector no está implementado. / documented; the detector is not implemented.

## Español

Enviar valor nativo a `address(0)` no quema ese USDC. En Arc la transferencia revierte con una dirección cero no permitida. Un burn nativo copiado de Ethereum se convierte en un revert.

**Qué debe marcar:** transferencias de valor cuyo destino es la dirección cero, incluidos burns nativos.

**Dirección del arreglo:** no usar `address(0)` como destino de valor. Si el protocolo necesita destruir unidades, usar el mecanismo de burn del ERC-20 que corresponda y cubrirlo en Arc testnet.

## English

Sending native value to `address(0)` does not burn that USDC. On Arc the transfer reverts because the zero address is not allowed. A native burn copied from Ethereum becomes a revert.

**What to flag:** value transfers whose recipient is the zero address, including native burns.

**Fix direction:** do not use `address(0)` as a value recipient. If the protocol needs to destroy units, use the ERC-20 burn that applies and cover it on Arc testnet.
