# ARC-008 `prevrandao-randomness`

**Severidad / Severity:** Alta / High

**Estado / Status:** documentada; el detector no está implementado. / documented; the detector is not implemented.

## Español

`block.prevrandao` y `block.difficulty` no son una fuente de aleatoriedad en Arc: el valor es 0. Un sorteo, un commit-reveal o un salto de lógica que depende de ese campo queda fijo.

**Qué debe marcar:** lecturas de `block.prevrandao` o `block.difficulty` usadas como entropía o como semilla.

**Dirección del arreglo:** sacar esa lectura del camino de decisión. Si el protocolo necesita aleatoriedad, usar una fuente documentada para Arc y no el campo que aquí es constante.

## English

`block.prevrandao` and `block.difficulty` are not a randomness source on Arc: the value is 0. A draw, a commit-reveal, or a branch that depends on that field is fixed.

**What to flag:** reads of `block.prevrandao` or `block.difficulty` used as entropy or as a seed.

**Fix direction:** remove that read from the decision path. If the protocol needs randomness, use a source documented for Arc rather than the field that is constant here.
