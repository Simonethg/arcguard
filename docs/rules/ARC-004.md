# ARC-004 `weth-pattern`

**Severidad / Severity:** Media / Medium

**Estado / Status:** documentada; el detector no está implementado. / documented; the detector is not implemented.

## Español

El patrón WETH (`deposit`, `withdraw`, constantes de WETH, wrap y unwrap) asume un nativo que se envuelve en un ERC-20 distinto. En Arc el nativo ya es USDC. Portar ese patrón no envuelve ETH.

**Qué debe marcar:** llamadas `deposit` / `withdraw` de WETH, constantes WETH y flujos de wrap o unwrap.

**Dirección del arreglo:** borrar el wrap. Mover USDC nativo o ERC-20 según la representación que el contrato realmente necesita.

## English

The WETH pattern (`deposit`, `withdraw`, WETH constants, wrap, and unwrap) assumes a native asset that is wrapped into a different ERC-20. On Arc the native asset is already USDC. Porting that pattern does not wrap ETH.

**What to flag:** WETH `deposit` / `withdraw` calls, WETH constants, and wrap or unwrap flows.

**Fix direction:** drop the wrap. Move native or ERC-20 USDC according to the representation the contract actually needs.
